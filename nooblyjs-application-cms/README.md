# nooblyjs-apps-cms
This repository holds the code for a micro-service that exposes a CMS application using the Nooblyjs framework.

The CMS is in early development. Today the service starts the NooblyJS Core services and serves a landing page and the project documentation.

## Getting Started

```bash
npm install      # nooblyjs-core is installed from ../../nooblyjs-core
npm run dev      # http://localhost:3004 (override with PORT)
```

See [docs/quickstart.md](docs/quickstart.md) for details and [docs/index.md](docs/index.md) for the planning documents.
